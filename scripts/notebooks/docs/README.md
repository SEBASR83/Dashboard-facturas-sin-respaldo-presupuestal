# Dashboard de facturas sin respaldo presupuestal

## Descripción del proyecto

Proyecto académico de analítica de datos orientado al desarrollo de un dashboard para analizar facturas sin respaldo presupuestal por servicios de salud en una entidad pública colombiana.

## Objetivo

Preparar, transformar y analizar los registros de facturas sin respaldo presupuestal mediante un proceso ETL, un modelo dimensional y visualizaciones que faciliten el análisis de la información.

## Componentes del proyecto

- `scripts/`: código fuente del proceso ETL.
- `notebooks/`: cuadernos utilizados para la preparación y transformación de los datos.
- `docs/`: documentación técnica y bitácora de decisiones.

## Datos

La base de datos original tiene carácter institucional y no se publica en este repositorio. Los archivos compartidos deben limitarse a código, documentación y resultados agregados autorizados.

Versión de trabajo correspondiente a la entrega académica ACA2: `v0.2`.
